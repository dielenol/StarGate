# 마가렛 회수 2부 준비·검증 기록

## ERP에 추가·수정한 내용

운영 등록 전 검수 단계다. 운영 08.5 보고서·신규 위키·웩슬러 주니어 신원은 저장 대기다. 격리 ERP에는 검수용 08.5 보고서, 같은 내용의 위키판, 시간인지 간섭과 미래 예시 위키, 웩슬러 주니어 비공개 신원, 도트 아이콘이 있는 물품 시안 세 건을 등록해 저장 내용을 다시 불러왔다.

운영 등록을 검토할 범위는 보고서와 위키 두 건(V 이상), 웩슬러 주니어 비공개 신원(GM)이다. 이 묶음에는 운영에 이미 올라간 공용 문장과 사용자 제공 초상만 사용한다. [제한 열람 등록안](nosb-s1e8-margaret-recovery-part2-limited-review-payload.json)

## 사용자가 확인할 내용

- [전체 검수안](nosb-s1e8-margaret-recovery-part2-user-review.md)에 98개 대상의 화면별 처리, 신원 후보와 독립 도트 아이콘 3점을 모았다.
- [작전보고서 검토본](nosb-s1e8-margaret-recovery-part2-report.md)에는 마가렛의 생포, 존 웡과 수잔의 사망, 네베드의 전근 신청, 웩슬러 주니어의 발표를 구분해 담았다. 28개 장면과 기존 공용 문장은 검수용 보고서와 위키판에서 같은 순서와 설명으로 제안했다.
- 웩슬러 주니어는 기존 웩슬러 부통령과 다른 인물이다. 미합중국 대통령·미국 분류·사용자 제공 초상·기존 부자 관계를 사용하며, 내부 등급은 설정하지 않는다. 비공개 신원은 GM 화면에 표시하고 그 화면에서 08.5 보고서를 열 수 있게 한다.

## 검토안으로만 남긴 내용 / 건드리지 않은 내용

- 기존 마리아 사망의 확인 기록과 마리아를 모방한 개체의 행동을 분리했다. 모방 개체의 독립 신원과 작틸의 분류·초상, 광체 소녀와의 관계는 검토 대상이다. 정체가 확정되기 전 기존 신원에 합치지 않는다.
- 존 웡·수잔 사망 표시, 기존 요원의 08.5 출현 및 관찰, 스타크의 M 표시, 기존 데드 핸드·원탁 기사단 위키와 불칼·USB 설명 보강은 기존 공개 기록의 후속 승인 범위다. 네베드의 기존 섹터 A·G와 개럿의 섹터 B는 원문에서 구조화 변경을 확정할 수 없어 유지하는 안이다.
- 주사기총과 사백신의 카탈로그는 아이콘 채택 대상으로 준비했다. 타다 만 편지는 우선 사건 관계에서 다루는 것이 적절하다. 웩슬러의 역사적 평가 발언은 자료에 보존했으며 장기 성격 표시의 근거는 미확정이다.
- 불칼은 피펫이 반납하겠다고 한 회수품이다. 공병 호출·치료 비용과 스팀팩·파쇄음절탄은 이전 장부에 반영됐는지 확인할 수 없어 중복 정산하지 않는다.
- 공적은 피펫(구조·보호), 네베드(전투), 스타크(지휘)를 예비 제안했다. 세 인물의 현역 소유 요원 여부를 확인했다. 실제 발급은 회원 공개안의 본문과 두 근거를 확정한 뒤 같은 승인 범위에서 진행한다.

## 이번 작업에서 끝낸 내용

- 원문 110쪽, 시각 표식 1,337개, 장면 도판 50개의 페이지와 시각을 두 추출기·독립 검수로 대조했다. 확인된 사실, 증언, 관측과 편집 보류를 나눴다.
- 운영의 08과 8-2 제목·번호·인물·물품을 읽기 전용으로 대조했다. 기존 USB·불칼·휴대용 EMP 총·파쇄음절탄을 재사용하며, 인덱서 사백신과 이사회 시제품·사용 주사기 표본을 구분했다.
- 08.5의 정규 번호와 독립 지도 카드, 위치 미분류 카드의 배치를 준비했다. 새 뉴욕 카드 때문에 기존 미니 카드가 밀려 안내에 가리는 현상을 지도 배치에서 수정했다.
- 관련 물품을 계산할 때 보고서·위키의 자체 회차와 본문에 인용한 이전 회차를 구분하도록 수정했다. 08에만 등장한 EMP 수류탄과 백신 시제품은 08.5 관련 목록에서 빠지고, 두 회차에 등장한 USB 링크는 양쪽에 표시된다.
- 28개 원본 도판을 화면 크기·프레이밍을 유지한 WebP로 보관하고, 별도 도트 시안 세 건은 실제 사용 크기와 네 가지 배경에서 독립 검수했다. [근거·자산 원장](nosb-s1e8-margaret-recovery-part2-coverage.md)

## 아직 끝나지 않은 일

- 운영용 등록 파일을 확정하고 네 항목을 제한 범위로 저장하는 단계가 남았다. 이미지 28개와 새 물품 아이콘의 웹 공개는 각 역할과 공개 범위 결정에 맞춘다.
- 기존 신원의 표시와 회차 연결, 기존 물품과 위키 본문, 회원 공개와 공적 발급은 통합 범위를 정한 뒤 적용한다. 8-1의 딕 체니·메트로 독성 개체는 새 근거가 생기면 재검토한다.
- 전체 원장 감사에서 기존 지적 77개를 재현했다. 저장소 본체에서는 실행용 08.5 등록 파일이 대기 중이어서 파일 부재와 회차 미등록이 각각 표시된다. 검수안과 자산을 올린 격리 트리에서는 기존 77개 외 추가 지적이 0건이었다.

## 진행에 필요한 확인·자료

- 먼저 08.5 보고서, 보고서 위키판, 시간인지 간섭 위키를 V 이상으로, 웩슬러 주니어 신원을 GM 전용으로 운영에 저장할지 결정한다.
- 새 아이콘 채택, 타다 만 편지의 별도 물품 추적, 스타크의 캐릭터 카드 직책과 M 표시, 마리아 모방 개체 및 작틸의 별도 신원 범위는 검수안의 제안을 기준으로 확인한다.
- 별도 신원을 만들기로 하면 각각 정확한 분류·소속과 전용 초상 또는 무이미지 여부가 필요하다. 네베드의 정식 인사 발령과 피펫의 새 인가는 후속 근거가 있으면 보강한다.

## 다음에 할 일

1. 사용자 확인을 반영하고 운영에서 웩슬러 주니어 이름·별칭·현직 대통령 직함의 중복과 08.5 및 위키 키를 다시 조회한다.
2. 승인된 네 항목을 저장용 파일로 확정한다. 지도와 카탈로그 수정을 적용할 운영 버전을 확인한 뒤 사전 검사 결과를 대조한다. 저장 직후 같은 항목을 불러와 값, 공개 범위, 두 위키와 관련 화면 링크, 지도 번호를 확인한다.
3. 채택된 이미지와 회원 공개 범위가 확정되면 기존 인물·위키·카탈로그의 보강과 공적 근거를 함께 다시 검증한다.

## 실제로 확인한 내용

- 출처·전체 대상·검수안의 일치, 신원·배치 원장, 자산·성격 근거 원장, 웩슬러 주니어만 포함한 등록 범위 검사와 보고서 원본·위키판 도판 일치를 확인했다. 제한안은 공용 문장 한 장, 격리 화면안은 공용 문장과 같은 순서의 장면 28개다.
- 운영 복제 데이터와 분리한 테스트 DB에서 제한안 4건과 전체 검수안 7건의 사전 검사가 통과했다. 전체 검수안의 테스트 저장 후 보고서 번호·V 등급, 위키 본문, 신원 공개 범위와 부자 관계, 물품 항목을 재확인했다.
- 운영을 읽기 전용으로 조회했다. 웩슬러 주니어와 이름·별칭·직함이 같은 신원 후보는 0건이었고, 제한안 사전 검사에서 위키 2건·신원 1건·보고서 1건 모두 신규 등록으로 판정됐다.
- 1280×900 작전지도에서 08·08.5 카드를 각각 눌러 연결을 확인했다. 390×844에서도 08.5가 보이고 해당 보고서가 열렸다. 두 카드의 데스크톱 안내가 가리는 다른 카드는 0건이었다.
- 격리 보고서와 위키판의 장면 28장 모두 원본 1035×503 비율로 표시됐으며 순서·경로·대체 문구·캡션이 일치했다. 대표 장면은 데스크톱에서 보고서 662×322, 위키판 732×356, 모바일 보고서 322×156으로 표시됐다. 원본 프레임을 자르지 않았고 같은 장면을 흐린 배경으로 표시했다. 최종 수정 문장도 두 화면에서 다시 확인했다.
- V 계정에서 세 물품의 분류 목록·상세 아이콘과 USB의 양방향 연결을 확인했다. 갤러리에서 08.5 앨범을 선택해 장면 28장, 첫 장면 확대 화면과 보고서 링크를 확인했다. A 계정에서는 제한 보고서·위키·물품·신원과 갤러리 장면이 보이지 않았다. GM 계정에서 미국 분류의 웩슬러 주니어 초상과 08.5 출현 링크가 열렸다.
- 확인한 화면의 브라우저 실행 오류는 0건이었다. 독립 코드·자료 검수, 회차·연결·권한 집중 테스트 41건, 타입 검사, 린트를 통과했다. 화면 캡처 12장은 격리 ERP에서 촬영했다.
