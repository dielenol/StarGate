# 로그 동기화 검토안

> 현재 단계: 원문·등록안 보완 완료, 신규 신원조회 6명의 전용 초상 원본 대기. 운영 ERP 저장은 아직 하지 않았다.

## 먼저 볼 내용

- 인형사는 **1부 코르티잔과 동일인**으로 연결한다. 후작·성직자는 **본인·인형 여부 미확정**을 유지한다. 두 결정을 다시 묻지 않는다.
- 인형사·후작·성직자·마테오·거울 속 계약 상대·파리 보스는 각각 신원조회 등록안에 포함한다. 새 6명은 외부 인물이므로 내부 권한등급을 부여하지 않고, 실명·기관·나이 등 확인되지 않은 값은 미상으로 둔다.
- 사용자가 선택한 대로 **전용 초상 확정 뒤** 등록안을 마무리한다. 아래 남은 질문은 여섯 명 각각의 정확한 원본 파일이다. 등록 여부를 반복 확인하는 질문은 없다.
- 기존 17명의 등장 사건, 새 장소·개체·개념 위키, 물품 정보 3종과 기존 행동교정물질 보강은 로컬 검증을 통과했다. 신규 6명의 신원 생성·양방향 링크는 초상 확정 뒤 기존 등록안에 함께 보강한다.
- 원문에서 누락됐던 마리아 내면의 목소리와 두목 인형의 위치 이동 사건을 보강했다. 현장 등장과 회상·증언 속 인물은 구별했다.

## 전용 초상 원본의 현재 상태

| 인물 | 확인한 원문 그림 | 필요한 원본 |
|---|---|---|
| 인형사·파리 보스 | [파리의 두 인물 장면](../../../StarGateV2/public/assets/session-reports/s1e7-desire-part2/puppeteer-and-boss.webp). 두 인물이 겹치며 모자·신체가 잘린 1035×503 장면이다. | 각 인물의 분리된 전용 원본 또는 사용자가 지정한 원본 |
| 후작·성직자 | [흑미사 유적 그림](../../../StarGateV2/public/assets/session-reports/s1e7-desire-part2/black-mass-ruins.webp)은 장소 그림이다. 대화 아바타는 작은 썸네일이다. | 두 인물 각각의 전용 초상 원본 |
| 마테오 | [접선 장면](../../../StarGateV2/public/assets/session-reports/s1e7-desire-part2/matteo-informant.webp). 모자 윗부분과 신체가 잘린 1035×503 장면이다. | 해당 마테오의 전용 원본; 병기부 마테오 리바스의 초상과 구별 |
| 거울 속 계약 상대 | [계약 요구 장면](../../../StarGateV2/public/assets/session-reports/s1e7-desire-part2/demon-contract-demand.webp). 얼굴 일부와 신체가 잘린 1035×503 장면이다. | 이 존재의 신원조회에 사용할 정확한 형상과 원본 |

현재 그림을 새로 생성하거나 신원조회 초상으로 발행하지 않았다. 이 그림들의 보고서·위키판 장면 용도는 유지한다.

등록 제안과 남은 결정을 정리한 문서다. 실제 ERP 저장·화면 검증 결과가 아니다.
