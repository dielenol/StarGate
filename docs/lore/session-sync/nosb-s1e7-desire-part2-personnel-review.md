# 욕구 2부 신원조회 검토안

**운영 ERP에는 아직 등록하지 않았다. 기존 인물 17명의 등장 기록 보강안만 준비됐으며 아래 신규 후보는 빠져 있었다.** 이 문서는 사용자에게 제시하지 않은 검토 대상을 복구한다. 앞서 제시한 전체 공개 확인보다 아래 인물 검토가 먼저다.

## 공통 추천값과 근거

- 실명이 없으면 확인된 호칭을 표시 이름으로 사용하고 실명 미상을 명시한다. 실명·나이·신장·체중이 없다는 이유만으로 신원조회 자체를 배제하지 않는다.
- 아래 인물들은 노부스 오르도 내부 인가 근거가 없으므로 **권한등급을 부여하지 않는 안**을 추천한다. 등급을 U/J로 임의 채우지 않는다. 현행 NPC schema에서 agentLevel과 정규 소속 필드는 생략 가능하고, 기존 외부 인물 `JOHAN_SMITH`·`STAR_MART`·`TOWASKI`도 등급을 생략한 기록이 있다.
- 신규 인물은 비공개 초안으로 준비한다. 지금은 전체 공개 여부를 다시 묻지 않는다.
- 사용자는 신규 6명 모두 전용 초상을 확정한 뒤 등록안을 마무리하도록 선택했다. 각 인물의 정확한 원본 파일만 남아 있다. 원본이 지정되면 실제 투명 배경과 피사체 보존을 확인해 신원조회 자산을 준비한다. 보고서 장면이나 작은 아바타를 자동 재사용하지 않는다.
- 새 영문 키는 아래에 기술적인 후보로만 기재한다. 화면에 공식 코드네임처럼 제시하지 않으며 신원 확정 후 중복 검사를 거친다.
- 사망/생포/조종은 별도다. 마테오·성직자의 사망은 원문 확인 사항이며, 후작의 무력화와 오틸리아의 소실을 사망으로 확장하지 않는다. 인형사의 최초 사망·머리/손 회수는 시간 회귀로 취소됐다.

**2026-09-07 사용자 결정:** 인형사는 코르티잔과 동일인이다. 후작·성직자는 본인·인형 여부 미확정으로 유지한다. 신규 6명은 전용 초상을 확정한 뒤 등록안을 마무리한다. 이 세 가지 결정을 다시 묻지 않는다. 실명·수치의 미상 값은 새로 만들어 달라고 요구하지 않는다.

사용자 결정이 반영된 NPC 원장→해당 인물 등록안과 링크 보강→검증. 인물 검토 완료 또는 사용자의 명시적인 연기/제외 뒤 전체 공개 범위를 논의한다.

## 실제로 확인한 내용

운영 DB에서 2부 보고서 0·등장 기록 0을 확인했다. 외부 NPC 스키마·기존 승인 사례, 원문 p26~29/35~36/44~49/54~55/62~65/94/113~120 및 기존 1부 보류 기록을 대조했다. 신규 후보 6명과 기존 NPC 2명을 포함한 원장 구조 검사와 완료 보고 형식 검사는 통과했다. 적용 준비 검사는 전용 초상 원본이 미지정된 신규 후보 6명을 모두 차단했다(종료 코드 1). 이는 등록 준비가 완료되지 않았다는 확인이며 통과로 보고하지 않는다.
