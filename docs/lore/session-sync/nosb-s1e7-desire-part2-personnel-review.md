# 욕구 2부 신원조회 검토안

**운영 ERP에는 아직 등록하지 않았다. 기존 인물 17명의 등장 기록 보강안만 준비됐으며 아래 신규 후보는 빠져 있었다.** 이 문서는 사용자에게 제시하지 않은 검토 대상을 복구한다. 앞서 제시한 전체 공개 확인보다 아래 인물 검토가 먼저다.

## 공통 추천값과 근거

- 실명이 없으면 확인된 호칭을 표시 이름으로 사용하고 실명 미상을 명시한다. 실명·나이·신장·체중이 없다는 이유만으로 신원조회 자체를 배제하지 않는다.
- 아래 인물들은 노부스 오르도 내부 인가 근거가 없으므로 **권한등급을 부여하지 않는 안**을 추천한다. 등급을 U/J로 임의 채우지 않는다. 현행 NPC schema에서 agentLevel과 정규 소속 필드는 생략 가능하고, 기존 외부 인물 `JOHAN_SMITH`·`STAR_MART`·`TOWASKI`도 등급을 생략한 기록이 있다.
- 신규 인물은 비공개 초안으로 준비한다. 지금은 전체 공개 여부를 다시 묻지 않는다.
- 초상은 아직 모두 미승인이다. 선택은 ① 전용 초상 확정 전까지 이미지 없이 등록 ② 전용 초상을 정한 뒤 등록 ③ 로그 속 정확한 인물 장면의 재사용을 승인하고 신원조회용 가공 가능성을 검토하는 방식이다. ③은 보고서 그림을 그대로 붙이는 뜻이 아니며, 적용 시 실제 투명 배경을 포함한 자산 준비와 검증이 필요하다.
- 새 영문 키는 아래에 기술적인 후보로만 기재한다. 화면에 공식 코드네임처럼 제시하지 않으며 신원 확정 후 중복 검사를 거친다.
- 사망/생포/조종은 별도다. 마테오·성직자의 사망은 원문 확인 사항이며, 후작의 무력화와 오틸리아의 소실을 사망으로 확장하지 않는다. 인형사의 최초 사망·머리/손 회수는 시간 회귀로 취소됐다.

**핵심 정체 질문은 두 가지다:** 인형사=코르티잔인지, 후작·성직자가 1부의 실제 당사자인지 인형/대리체인지. 나머지 미상 인적 정보는 사용자에게 억지로 만들어 달라고 요구하지 않는다.

## 원장과 실제 등록 범위

- [전체 coverage 및 NPC Approval Ledger](nosb-s1e7-desire-part2-coverage.md): 기존 NPC 2명은 보강 준비, 신규 후보 6명은 결정 대기. 원장 전체의 apply-ready 검사는 현재 통과할 수 없다.
- 기존 17명: MARIA, OTILIA, INDEXER, 네베드, PIPETTE, YUHOE, ACCEL, KIMLEE, TIME, WD-(𝓃), AEGIS, CLOWN, CLAIRVOYANCE, LEE DONGSIK, BIG BOY, MR_ODD, MARGARET. 이 숫자는 신규 NPC 등록 숫자가 아니다.

- 수잔의 통제 성향·마가렛의 지속 성격에 대한 해석 후보, 오틸리아·피펫·우디 공훈 후보도 아직 운영에 쓰지 않았다. 현재 질문은 NPC 검토에 우선하며 전체 공개/공훈 실행 승인을 다시 요구하지 않는다.
