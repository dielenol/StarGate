# 로그 동기화 검토안


## 8-2 제한 열람안

작전보고서 **08.5 마가렛 회수 2부**, 같은 내용의 위키판, **시간인지 간섭과 미래 예시** 위키, **웩슬러 주니어** 신원조회 네 항목을 운영에 등록했다. 보고서·위키는 V 이상, 웩슬러 주니어의 비공개 신원은 GM이 볼 수 있다. 신원에서 이번 작전으로 돌아올 수 있으며, V 보고서에서 대통령 이름은 담화의 등장 인물로 읽힌다.

마가렛은 핀치의 마취 뒤 살아서 회수됐고, 존 웡과 수잔의 사망이 확인됐다. 기존 마리아와 같은 이름으로 행동한 개체는 분리했다. 수잔의 파리 폭파 자백과 미국 담화의 익명 제보는 각각 발언 기록으로 남긴다. 미국의 계엄 선포와 대노부스 오르도 선전포고는 공개 담화에서 확인됐다.

제한 등록안은 기존 공용 문장으로 두 문서의 도판을 맞췄다. 아래 장면과 도트 시안은 검수 중인 별도 자료다. 정적 파일을 운영에 올리면 이미지 주소 자체를 로그인 없이 열 수 있어, 채택과 웹 공개는 따로 확인한다. 기존 공개 신원에 붙을 사망·출현·관계와 기존 물품 설명은 같은 공개 범위가 정해질 때 함께 검토한다. 세 인물의 현역 소유 요원 신원을 정확히 대조했다. V 검토 단계에서는 공적·알림을 발급하지 않는다. 회원 공개 문구가 확정되면 두 독립 근거를 공개 보고서에서 다시 맞춰 공적 제안을 검증한다. 모방 개체의 옥상전 행동은 기존 마리아에게 공적으로 배정하지 않는다.

운영 등록과 격리·운영 화면 확인 결과는 [동기화·검증 기록](nosb-s1e8-margaret-recovery-part2-execution.md)에서 확인할 수 있다.
