# 9화 이미지 제작 자료

이 묶음은 **이미지 제작용 원본과 연결 정보**다. [시나리오 원문](scenario-source.txt)은 미진행 서사이며, 사건·사망·관계의 진행 결과를 운영 기록으로 확정하지 않는다. 원본 5장·시나리오·준비한 투명 WebP까지 모두 웹 `public/` 밖에 보존했다. ERP·갤러리에 자동 노출되지 않는다.

- [구조화 데이터](reference-data.json): 출처, 원본 해시·치수, 인물 식별자, 용도, 상태 전환, 컷별 연결과 남은 자료.
- [접속 장치 디자인 제안](device-design-proposal.md): 선택한 외부 참고와 구별해야 할 장치 5부분.
- [접수·검증 원장](../../session-sync/s1e9-visual-reference-intake-2026-09-07.md): NPC·이미지 용도 검토, 실제 검증과 운영 반영 상태.
- [웩슬러 주니어 명세](../../../../StarGateV2/docs/spec/npc/wexler-junior.md), [웩슬러 명세](../../../../StarGateV2/docs/spec/npc/wexler.md), [등록 준비 파일](../../../../StarGateV2/scripts/seed-payloads/s1e9-wexler-family-reference-intake.json).

등록 준비 파일은 **비공개 웩슬러 주니어 1명**만 포함한다. 주니어에서 아버지로 향하는 관계도 담았다. 공개 웩슬러의 역방향 관계는 현재 화면에서 비공개 대상 이름도 표시하므로 실행 대상에서 뺐고, 제작 데이터에만 보존했다. [검수된 초상](prepared-public/assets/npcs/Wexler-Junior-profile.webp)의 예상 웹 주소는 `/assets/npcs/Wexler-Junior-profile.webp`이지만 아직 배포되지 않았다. 운영 적용 전 초상 공개 범위·배포와 정확한 인물 추가 승인이 필요하다.

## 가족 얼굴 대응 후보

사용자는 **같은 가족이라는 점**을 확정했다. 아래 인물별 위치 대응은 보존된 컷과 사건의 행동 묘사를 대조한 후보다.

| 인물 | 기존 이미지와 대응 근거 | 상태 |
|---|---|---|
| 백진연 | 화양연화 020 영정·056 얼굴, 069의 故 백진연군 표기 | 영정 후보. 054 흔들리는 사진에 재사용하려면 구도를 선택 |
| 어머니 최선영 | 071 오른쪽·073의 긴 회색 머리 여성. 운연의 팔을 붙드는 행동이 본문과 대응 | 근거가 강한 후보 |
| 아버지 백진욱 | 032·033·070·072의 회색 머리 남성 | 가족 내 역할 대응 후보 |
| 고모 백민희 | 같은 장면의 짧은 검은 머리 여성 | 가족 내 역할 대응 후보 |
| 운연의 인간 모습 | 070·071 왼쪽의 젊은 검은 머리 남성 | 회상 상태 후보. 현재 연기 머리 모습과 분리 |

숫자는 `public/assets/session-reports/hwayangyeonhwa/cut-NNN.webp`의 번호다. 새 9화 컷 번호와 혼동하지 않는다. 개인별 신원조회 초상으로 승격하거나 잘라 저장하지 않았다.

과거 유리창 면회의 정확한 두 손 구도는 전용 원본이 아직 없지만, 기존 면회 컷과 두 인물의 초상으로 새 장면을 설계할 수 있다. 원로 개인 이름, 몬탁 개체 번호, 대통령의 나이·신장은 이미지 제작의 필수 입력이 아니다. 최종 앵커 공격자는 시나리오 지시대로 화면 밖에 두어 플레이 결과를 기다릴 수 있다.

## 제작 시 유지할 경계

- 원로 사진 속 얼굴은 가면이다. 하이퍼보리아 표본 14와 같은 개인으로 연결하지 않는다.
- 몬탁 갑각류형은 기존 몬탁 98 장면과 닮았지만 동일 개체라는 확인은 없다. 사족수도 기존 미사일 도살견과 같은 개체로 합치지 않는다.
- 해쉬·피펫을 시체 재기동 군중에 넣지 않는다. 운연 소멸과 마가렛의 최종 생사·원로의 포식 결과를 운영 상태에 미리 저장하지 않는다.
- 63컷은 가로 16:9, 한 시점·한 순간. 표지·대사·숫자는 후편집한다. 실제 생성은 이 묶음을 참조하는 후속 제작 작업이다.
