# 마가렛 접속 장치 — 제작 디자인 제안

상태: `design-proposal`. 사용자가 적절한 레퍼런스 탐색을 맡긴 범위에서 고른 형태 제안이다. 확정된 장치 사진이나 완료 사건으로 취급하지 않는다. 기능과 상태 전환은 [9화 원문](scenario-source.txt)을 따른다.

## 선택한 외부 레퍼런스

| 참고 | 채택할 요소 | 채택하지 않을 요소 |
|---|---|---|
| [H.R. Giger 공식 Harkonnen Chairs](https://www.hrgiger.com/new_chairs.htm) | 인체보다 훨씬 높은 등받이, 갈비뼈 같은 지지대, 몸을 둘러싸는 어두운 구조 | 작품의 이름·해골 장식·세계관을 오르도 설정으로 옮기지 않음 |
| [ITER 공식 Assembly tooling](https://www.iter.org/project/assembly-tooling) | 두꺼운 환형 모듈, 외부 지지 프레임, 거대한 설비 옆에 작은 사람이 서는 크기 대비 | ITER 로고·작업장 색상·실제 핵융합 작동 원리를 데드 핸드 설정으로 옮기지 않음 |

공식 페이지와 의자 사진·ITER 중앙 솔레노이드 설치 사진을 직접 열어 확인했다. 외부 사진은 링크로만 보존하며 다운로드·재배포하지 않았다. 피라미드의 재질·문양은 기존 회랑 그림을 우선한다.

## 반복 제작 규칙

- 위 형태·재질·배치·균열 모양은 제안이다. 첫 장치 기준 컷을 채택한 뒤 다음 컷에서도 고정한다.
- 통제 접속부의 파괴가 마가렛의 능력 상실이나 재접속 불가능을 뜻하지 않는다.
- 의자·잠금 구조·앵커·핵심부를 하나의 파괴물로 그리지 않는다. 앵커 수는 정확히 3기다.
- 보스 그림의 옅은 청색 흐름을 연결 표현에 참고한다. 광원화 감염자의 다색 내부 굴절광과 구분한다.
- 장치의 글자·수치·인증 결과는 후편집한다. 실제 제품명·현실 기관명은 완성 이미지에 넣지 않는다.
- 정밀 크기·재질명·기술 번호·게임 수치는 새 canon으로 만들지 않는다.
