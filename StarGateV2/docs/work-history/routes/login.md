# /login — 요원 인증

## 2026-09-07 · UI 개선 · 인증 화면과 로그인 피드백

- 승인된 요원 신분증·명찰 이미지를 사용하는 검정·골드 로그인 화면을 구성했다. 데스크톱은 이미지와 인증 폼을 나란히 배치하고, 모바일은 짧은 이미지 영역 아래에 폼을 배치한다. 공개 메인 복귀 링크와 서버 렌더링된 화면·준비 안내를 제공한다.
- 아이디·비밀번호의 빈 입력을 해당 필드에서 안내하며 비밀번호 표시와 Caps Lock 안내를 추가했다. 인증 중에는 버튼의 스피너·상태 문구를 표시하고 세 로그인 수단의 중복 제출을 막는다.
- Credentials·게스트·Discord 인증 응답을 처리하고 오류를 폼 안에서 안내한다. 실패 시 입력을 보존하고 재시도를 허용하며, OAuth 오류로 복귀한 경우에도 오류 안내에 포커스를 이동한다.
- 기존 `/erp` 콜백 허용 범위와 서버 인증·권한 정책을 유지한다. 처리 중 메인으로 이탈한 뒤 늦게 끝난 요청은 화면을 이동시키지 않으며, 성공 또는 브라우저 복원 시 비밀번호와 표시 상태를 비운다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과. 임시 Playwright harness에서 입력 검증, 비밀번호 표시·Caps Lock, 지연 응답·중복 방지, 실패·통신 오류·일반 오류 복구, 콜백 보존·외부 목적지 차단, Discord 이동·복귀, 처리 중 이탈, OAuth 오류 포커스, 반응형·모션 감소, 실제 테스트 계정 로그인의 12개 시나리오를 통과했다. uncaught page error 0건. 완성본 재로딩 후 콘솔 오류·경고 0건.
- 320·390·760·768·1024·1280·1440px에서 가로 넘침 없음과 44px 이상 주요 버튼을 확인했다. 실제 로컬 테스트 계정으로 로그인 후 `/erp/account` 이동과 인증 세션을 확인했다.
- 읽기 전용 인증 위험 리뷰에서 발견한 복원 시 비밀번호 잔존, 이탈 후 늦은 이동, 쿼리 기반 오류 포커스 누락을 수정하고 최종 리뷰를 통과했다.
- 검증 경계: 지연·실패·외부 OAuth 이동은 모의 인증 응답으로 검증했다. 실제 Discord 계정 승인·생성이나 라이브 ERP 데이터 변경은 실행하지 않았다.
- 관련 커밋: `42c8295f`

## 2026-10-17 · UI 개선 · 공개 첫 화면과 문장 모션 통일

- 신분증 사진 패널을 공식 로고 중심의 `BrandMotion`으로 교체하고 검정·골드, 얇은 구획선, 넓은 여백으로 공개 메인과 시각 체계를 통일했다. 헤더에는 기존 투명 WebP 로고를 사용한다.
- 데스크톱은 문장과 인증 폼을 나란히 배치하고 모바일은 180~200px 문장과 짧은 제목 아래에 폼을 둔다. 입력칸·오류·로그인 처리·Discord·게스트 접속 로직은 변경하지 않았다.
- 검증: `pnpm typecheck`, `pnpm lint`, 변경 파일 ESLint, `git diff --check` 및 독립 읽기 전용 리뷰 통과. 로컬 개발 브라우저에서 실측 320·390·760·761·768·1440px 렌더링과 가로 넘침 없음, 좁은 화면 하단 버튼·오류 문구를 직접 확인했다. 아이디/비밀번호 빈 입력 안내와 해당 필드 포커스, 비밀번호 표시 전환, 문장 모션 실행·정지·재생을 확인했다.
- 검증 경계: OS 모션 감소 설정 전환은 도구 미지원으로 미검증이며 CSS 분기는 코드 리뷰로 확인했다. 실제 로그인·외부 OAuth·게스트 인증·라이브 데이터 mutation과 운영 배포는 수행하지 않았다. 공개 메인의 기존 smooth-scroll 안내 경고 외 브라우저 런타임 오류는 관찰되지 않았다.
- 관련 커밋: `0e5f92f1`
