## 2026-09-07 · UI 개선 · 헤더 정렬과 카드 이미지 통일

- 사용자가 제보한 헤더 정렬을 재현했다. 기존 메뉴 SVG 중심이 버튼에서 가로·세로 1px씩 밀렸고, 검색 아이콘은 단축키 문자와 함께 배치되어 버튼 중심에서 치우쳐 보였다. 검색·메뉴 버튼을 44×44px, padding 0으로 통일해 아이콘 중심 오차를 0px로 맞췄다.
- 헤더·첫 화면 버튼은 12px, 카드·기록 뷰어는 18px 모서리로 정리했다. 뷰어 탭과 하단 목차도 둥근 형태로 맞췄다. 첫 화면 버튼은 데스크톱 54px, 모바일 48px 높이로 일치한다.
- 룰의 작전 매뉴얼 열람실, 플레이어의 인사 기록실을 `stargate-images` 환경 배경 워크플로와 built-in image_gen으로 생성했다. 불투명 4:3 WebP로 발행하고, 세계관과 동일한 전면 이미지·상단 라벨·본문·이동 링크 구성으로 연결했다. 세 카드 폭·높이와 좁은 화면에서 제목 시작점을 맞췄다.
- 생성 프롬프트와 실제 발행 규격·해시는 `docs/design/public-archive-images.md`에 기록했다.
- 검증: `pnpm typecheck`, `pnpm lint`, `pnpm assets:audit`, `pnpm assets:test` 23/23, `git diff --check` 통과. 320·390·768·1024·1280·1440px에서 넘침·이미지 로드·버튼 중심과 제목 정렬 확인. 완성본 재로딩 후 콘솔 경고·오류 없음.
