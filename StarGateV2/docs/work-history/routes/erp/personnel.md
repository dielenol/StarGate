- 이름 마스킹 게이트를 redactNameFields 단일 지점으로 통합 (목록/참조/상세 3경로 공유).
- 검증: 마스킹 등가성 테스트 15건 신규, `pnpm lint`, `pnpm typecheck`, `pnpm build`
