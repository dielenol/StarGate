## 2026-09-08 · 기능 보강 · 홈에서 정확한 참여 작전 열기

- 홈에서 받은 `sessionId`·`source`·한국시간 날짜로 올바른 월과 목록을 열고 해당 작전을 펼쳐 표시한다. Registra와 TRPG에 같은 ID가 있어도 출처를 포함한 키로 구분한다.
- 잘못된 링크·삭제되거나 조회할 수 없는 작전을 안내하며, 사용자가 월·보기·항목을 바꾸면 초기 링크의 선택을 해제한다. 자동 갱신이 수동 접기 상태를 덮어쓰지 않는다.
- 검증: 세션 선택·날짜 파서 테스트 8건을 포함한 집중 테스트 43/43, `pnpm typecheck`, `pnpm lint`, `pnpm build`. 인증 브라우저에서 실제 작전의 월·출처·상세, 모바일, 수동 접기 후 갱신, 잘못된 링크와 뒤로·앞으로 이동을 확인했다.
- 관련 구현 커밋: `d7c28636`
- 운영 경계: 세션 생성·편집·참여 응답·Discord 발송은 실행하지 않았다.
