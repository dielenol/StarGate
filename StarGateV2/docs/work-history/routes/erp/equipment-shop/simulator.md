## 2026-07-28 · 기능 개선 · 캐릭터 토큰과 턴 종료 연출

- `현재 배치 기준 비교` 영역을 제거하고 공격 로그가 하단 전체 폭을 사용하도록 단순화
- 로그인한 사용자의 주 캐릭터 픽셀 프로필을 `내 캐릭터` 토큰으로 표시하고, 이미지가 없을 때는 `나` 대체 토큰을 제공
- `nochichim`의 턴 종료 HUD 타이밍과 효과음을 이식하고 다음 턴 안내음과 겹치지 않도록 조정
- 데스크톱과 모바일에서 전투 조작 버튼이 전투판 내부에 줄바꿈되도록 반응형 배치를 보강
- 검증: 시뮬레이터 테스트 15/15 통과, `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과, 효과음 원본 바이트 일치 및 로컬 응답 200 확인, 인증된 로컬 브라우저 1280px·390px에서 턴 종료 클릭·HUD 표시/종료·가로 넘침·콘솔 오류 확인
