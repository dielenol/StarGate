# `/erp/equipment-shop/towaski` 작업 이력

## 2026-07-30 · 기능 개선 · 라이선스 시험 조작 안내

- 모든 라이선스 브리핑과 실제 시험 화면에 3단계 코치마크를 추가하고, 카운트다운도 선택한 시험의 전용 화면과 준비 지시를 유지하도록 변경했다.
- 정밀사격은 표적과 득점 반경을 축소했으며, 중화기는 점사·냉각·횡단 인원 대응을 실시간으로 안내하도록 보강했다.
- 음파는 주파수·출력·파동 폭·안전 부하·충전 시간을 명시했고, 폭발물은 3단계 판단 퍼즐, 화염은 드래그 소각 경로 미니게임으로 재설계했다.
- 토와스키의 시험 시작·재시험 대사를 모드별 실제 조작 절차에 맞춰 보강했다.
- 검증: 관련 Node 테스트 35개 통과, `pnpm typecheck`, `pnpm lint`, `git diff --check`; GM `SANDBOX / DB WRITE 0`에서 음파·정밀사격·중화기·폭발물·화염 전용 카운트다운과 실제 화면 확인, 폭발물 3단계 전환 확인, 390px 모바일 가로 넘침 없음, 브라우저 콘솔 오류 없음
- 관련 커밋: `0eb6a7d`
- 후속 작업: 로컬 브라우저 환경의 `REALTIME_TICKET_SECRET` 미설정으로 실시간 티켓 API 503 로그가 발생했으나 라이선스 시험 동작 및 브라우저 콘솔에는 영향을 주지 않았다.

## 2026-07-30 · 기능 개편 · 라이선스 시험 V3

- 정밀사격은 기본 사격장의 12라운드 구성을 유지하면서 표적과 서버 명중 반경을 25%로 줄이고, 라운드 조작 시간을 1,125ms로 고정했다.
- 중화기는 기본 사격장 위에 서버와 클라이언트가 동일하게 재현하는 80ms 결정론적 조준 흔들림을 적용하고, 실제 탄착 판정을 가상 조준점 기준으로 교체했다.
- 음파 장비는 96·108·120·132 BPM의 4단계 실시간 리듬 시험, 폭발물은 수류탄·로켓 병기 검수 3분류 시험, 화염 장비는 7×5 격자의 3칸 소이선 배치 시험으로 전면 교체했다.
- V3는 좌표·입력 시각·기본 조준점·분류·시작 칸과 방향 같은 원시 입력만 서버에 제출한다. 화면 활성화 시 서버 시간이 한 번만 시작되며, V2 취득 자격과 지급 진행 기록은 보존하고 진행 중인 V2 시험만 V3 시작 시 재시작 처리한다.
- GM 샌드박스 판정을 무쓰기 서버 경로로 분리해 실제 지급·인벤토리·알림을 건드리지 않으면서 운영 판정기와 같은 결과를 확인할 수 있게 했다. 폭발물 정답 데이터와 판정 표현식은 클라이언트 번들에서 제외했다.
- 검증: 관련 Node 테스트 99개 중 90개 통과·9개 환경 조건부 스킵, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `git diff --check`, 클라이언트 번들 판정 패턴 0건. GM `SANDBOX / DB WRITE 0`에서 정밀사격·중화기·음파·폭발물·화염 시험을 1280×720 및 390×844로 직접 완주했고, 터치·마우스·키보드 조작, 가로 넘침, 현재 브라우저 콘솔 오류 없음과 정밀사격의 1,125ms 라운드 진행을 재확인했다. Critical risk review 결과 P0–P2 잔여 항목 없음.
- 관련 커밋: `62dfbc6`
- 후속 작업: 실제 MongoDB의 CAS 경쟁과 transaction 재시도 9건은 `RUN_DB_INTEGRATION_TESTS=1` 및 `MONGODB_TEST_URI`가 없어 실행하지 않았다. 라이브 DB 쓰기는 수행하지 않았다.

## 2026-07-31 · 사용성 개선 · 음파 장비 시험 피드백

- 시험 화면에 포커스가 없어도 Space로 펄스를 입력할 수 있게 하고, 시험장 탭·PULSE 버튼과 동일한 원시 입력 경로를 사용하도록 통일했다.
- 입력 순간 `PERFECT`·`GOOD`·`MISS`·`PROTECTED` 판정과 코어 충격 효과를 표시하고, 각 박자에 적중·실패·보호 통과 상태와 현재 TARGET 적중 수를 남기도록 보강했다.
- 다음 스테이지에서 직전 결과의 `CLEAR`·`FAILED`, TARGET 적중 수, 보호 박자 위반 여부를 계속 확인할 수 있게 했다.
- 브리핑에 TARGET·PROTECTED 구분, 세 가지 조작법, 판정 구간, 단계·최종 합격 조건을 음파 전용 패널로 추가하고, 리듬 부족 실패 대사가 보호 박자 위반으로 잘못 안내되던 문제를 수정했다.
- 검증: 관련 Node 테스트 39개 통과, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `git diff --check`. GM `SANDBOX / DB WRITE 0`에서 1280×720 본문 포커스 상태의 Space 입력으로 TARGET 6/6·보호 입력 0 스테이지 통과, 390×844 시험장 탭 입력 피드백과 가로 넘침 없음, 로컬 서버 재시작 이후 브라우저 콘솔 오류·경고 없음 확인
- 관련 커밋: `634f580`
- 후속 작업: 라이브 DB 쓰기와 라이선스 지급은 수행하지 않았다.
