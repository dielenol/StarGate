- 검증: 공방·표결·seed 집중 테스트 72건, REGISTRAR 테스트 23건, 웹·REGISTRAR build, 인증된 로컬 투표 운영 화면과 콘솔 오류 0건 확인
- 관련 커밋: `c1dc0e5a`
- 운영 경계: Discord 관료 채널 게시와 라이브 표결 생성은 실행하지 않았다.

## 2026-08-07 · 문구 정정 및 운영 반영 · CENSOR-3 SAN 판정

- v2 제작 안건의 운용 효과를 `고정 15 소리 추가 피해와 SAN 추가 감소`가 아니라, 네베드의 패시브가 반영된 기본 물리 사격 뒤 방어 수단과 DEF를 무시해 SAN을 고정 15 감소시키는 판정으로 바로잡았다.
- `SOUND 15`가 별도의 HP 추가 피해가 아니라 SAN 감소량이라는 점, 액션 1·CENSOR-3 1발 소모와 일반 탄약 미소모 조건을 안건 본문에 명시했다.
- 운영 `DRAFT` 청사진을 v2 안건 키와 정정 본문으로 갱신했으며, 표결 원장 생성이나 Discord 게시는 실행하지 않았다. 재조회 시 해당 v2 표결은 0건이다.
- 검증: 관료 표결·공방 관련 계약 테스트 63건, `npm run typecheck`, `npm run lint`, 운영 DB 청사진 원문 재조회, critical risk review
- 관련 커밋: `a698e662`
