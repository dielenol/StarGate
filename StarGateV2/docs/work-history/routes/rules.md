- 턴당 이동 선언 횟수, 반올림 기준값과 맵 최소 크기를 공용 전투 규칙 데이터에서 직접 표시하도록 연결
- 문서 목차에 전투 근간 규칙 항목을 추가해 해당 규칙으로 바로 이동할 수 있도록 구성

- 관련 커밋: `4a59809e`

## 2026-08-04 · 기능 추가 · R 궁극기 규칙 공개

- 능력 메이킹 규칙에 캐릭터당 하나인 `R` 궁극기 전용 슬롯을 추가했다.
- `R`은 `A1~A5`와 분리되어 액티브 보유 한도를 차지하지 않으며 세부 발동 조건·비용·효과는 각 능력 설명을 우선하도록 명시했다.
- 검증: 공개 룰 계약을 포함한 관련 테스트 59건, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `git diff --check` 통과
- 브라우저 확인: 로컬 `/rules`에서 `R · 궁극기 슬롯` 제목과 세 운용 원칙 렌더링 확인
- 관련 커밋: `da2c2e3f`
