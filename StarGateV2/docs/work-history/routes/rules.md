# `/rules` 작업 이력

## 2026-08-03 · 기능 추가 · 전투 근간 규칙 공개

- 공개 노부스 오르도 룰에 이동 선언, 백분율 피해 소수점 처리, 클래식·리뉴얼 전투 맵 규격을 추가
- 턴당 이동 선언 횟수, 반올림 기준값과 맵 최소 크기를 공용 전투 규칙 데이터에서 직접 표시하도록 연결
- 문서 목차에 전투 근간 규칙 항목을 추가해 해당 규칙으로 바로 이동할 수 있도록 구성
- 검증: 공개 룰 계약을 포함한 관련 테스트 39/39, `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과
- 브라우저 확인: 로컬 `/rules`에서 목차와 이동 2회·0.5 기준·5×1·1×5·5×5 규격 렌더링 및 데스크톱 화면 배치 확인
- 관련 커밋: `4a59809e`

## 2026-08-04 · 기능 추가 · R 궁극기 규칙 공개

- 능력 메이킹 규칙에 캐릭터당 하나인 `R` 궁극기 전용 슬롯을 추가했다.
- `R`은 `A1~A5`와 분리되어 액티브 보유 한도를 차지하지 않으며 세부 발동 조건·비용·효과는 각 능력 설명을 우선하도록 명시했다.
- 검증: 공개 룰 계약을 포함한 관련 테스트 59건, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `git diff --check` 통과
- 브라우저 확인: 로컬 `/rules`에서 `R · 궁극기 슬롯` 제목과 세 운용 원칙 렌더링 확인
- 관련 커밋: `da2c2e3f`

## 2026-09-07 · UI 개선 · 공개 메인 및 탐색 개편

- 공개 상단 메뉴에서 주요 문서와 ERP로 바로 이동하고, 전체 메뉴·페이지 찾기를 데스크톱과 모바일에서 사용할 수 있게 했다.
- 문서 본문 폭을 사이드바 여백 없이 중앙에 배치하고 앵커 이동에 상단 메뉴 높이를 반영했다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check`, 인증된 로컬 브라우저 1280px·390px에서 헤더·문서 표시 및 가로 넘침 없음 확인
- 관련 커밋: `2b5e856b`

## 2026-09-07 · UI 고도화 · 공용 검색 키보드 탐색

- 공용 페이지 찾기에 `/`, `Ctrl/⌘ K` 단축키와 검색 결과의 방향키·Home·End·Enter 이동을 추가했다. 입력 중 단축키 충돌을 방지하고 닫을 때 이전 포커스를 복원한다.
- 메뉴를 끝까지 스크롤해도 닫기 버튼을 사용할 수 있도록 메뉴 제목과 닫기 영역을 고정했다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check`; 동일 공용 헤더를 사용하는 로컬 `/`·`/world`에서 검색 이동과 모달 종료·Ctrl K 토글, 390px 메뉴 닫기 및 빈 결과 확인. 기존 문서 레이아웃 검증은 앞선 이력의 결과를 재사용했다.
- 관련 커밋: `85e2cb02`

## 2026-09-07 · UI 개선 · 공개 헤더 버튼 정렬

- 공용 검색·메뉴 버튼을 44px 크기와 동일한 둥근 모서리로 맞추고, SVG가 버튼 중앙에 놓이도록 패딩을 제거했다. ERP 진입 버튼 높이·중심도 맞췄다. 검색 단축키와 접근성 이름은 유지한다.
- 검색·전체 메뉴 패널과 입력창의 모서리를 다듬고 모바일 전체 화면 메뉴의 화면 맞춤을 유지했다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과. 공용 헤더를 사용하는 `/`에서 320·390·768·1024·1280·1440px 정렬·넘침 검사, `/rules`·`/world/player`에서 모바일 검색·메뉴 이동과 닫힘 확인. 변경하지 않은 문서 본문 검증은 앞선 이력을 재사용했다.
- 관련 커밋: `24354b56`

## 2026-09-07 · UI 개선 · 문서 복귀와 GNB 강조

- 1100px 이하에서 문서 위에 이전 버튼과 현재 경로를 고정했다. 사이트 내 이동 기록이 있으면 이전 화면으로 돌아가며 새로고침 후에도 기록을 유지한다. 직접 진입 시 이전 버튼은 메인으로 연결되며 메인 경로 링크도 제공한다.
- 데스크톱 GNB에 기존 공용 아이콘·영문 분류·현재 메뉴 강조를 적용했다. 문서 앵커의 여백은 반응형 헤더 높이에 맞춘다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과. 390px 검색 Enter로 진입 시 패널 종료·현재 경로 표시와 가로 넘침 없음 확인. 룰 새로고침 후 이전→세계관→이전→메인 복귀 확인. 공용 헤더의 1101px 경계에서 메뉴·액션 겹침 없음 확인.
- 관련 커밋: `9b999f9b`

## 2026-09-07 · UI 정리 · 헤더 중첩 장식 제거

- 사용자가 제보한 GNB의 외곽 테두리·선택 박스·아이콘 배경·하단 밑줄을 제거했다. 배경 없는 아이콘과 글자, 메뉴 간 여백으로 정리하고 현재 메뉴는 금색으로 구분한다.
- 메뉴 한글은 14px, 영문 분류는 8px로 조정했다. 링크 높이는 48px이며 키보드 포커스 외곽선과 기존 선택 판정·모바일 복귀 동선은 유지한다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check` 통과. 인증 세션의 공용 헤더를 사용하는 `/world`·`/world/player`에서 1280·1440px 외관, 메뉴 배경·테두리 0 및 밑줄 없음, Tab 포커스·Enter 이동·플레이어 단독 선택 확인. 1101px에서 브랜드·메뉴·액션 사이 각각 73px 이상 간격과 가로 넘침 없음, 1100px에서 GNB 숨김·문서 경로 표시 확인. 390px에서 기존 128px 헤더·44px 이전 버튼과 넘침 없음 확인. 완성본 재로딩 후 콘솔 오류·경고 없음.
- 검증 범위: 이 페이지가 공유하는 헤더 스타일만 변경했다. 변경하지 않은 페이지 본문과 검색·이전 버튼 동작의 검증은 앞선 이력을 재사용했다.
- 관련 커밋: `62bdc9d6`
