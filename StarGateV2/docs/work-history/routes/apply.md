- 공개 상단 메뉴에서 주요 문서와 ERP로 바로 이동하고, 전체 메뉴·페이지 찾기를 데스크톱과 모바일에서 사용할 수 있게 했다.

## 2026-09-07 · UI 고도화 · 공용 검색 키보드 탐색

- 공용 페이지 찾기에 `/`, `Ctrl/⌘ K` 단축키와 검색 결과의 방향키·Home·End·Enter 이동을 추가했다. 입력 중 단축키 충돌을 방지하고 닫을 때 이전 포커스를 복원한다.
- 메뉴를 끝까지 스크롤해도 닫기 버튼을 사용할 수 있도록 메뉴 제목과 닫기 영역을 고정했다.
- 검증: `pnpm typecheck`, `pnpm lint`, `git diff --check`; 동일 공용 헤더를 사용하는 로컬 `/`·`/world`에서 검색 이동과 모달 종료·Ctrl K 토글, 390px 메뉴 닫기 및 빈 결과 확인. 기존 문서 레이아웃 검증은 앞선 이력의 결과를 재사용했다.
- 관련 커밋: `a624aae3`

## 2026-09-07 · UI 개선 · 공개 헤더 버튼 정렬

- 공용 검색·메뉴 버튼을 44px 크기와 동일한 둥근 모서리로 맞추고, SVG가 버튼 중앙에 놓이도록 패딩을 제거했다. ERP 진입 버튼 높이·중심도 맞췄다. 검색 단축키와 접근성 이름은 유지한다.
- 검색·전체 메뉴 패널과 입력창의 모서리를 다듬고 모바일 전체 화면 메뉴의 화면 맞춤을 유지했다.

- 관련 커밋: `cdc1c617`
