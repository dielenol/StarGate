# ERP 시각 체계

## 2026-06-29 · 도트 타이포그래피 확장

- 도트 폰트 토큰과 opt-in 스코프를 추가하고 상점·인벤토리·증권·알림·대시보드에 적용했다.
- 세션·리포트·크레딧과 세력·신원·캐릭터 보기 화면까지 하이브리드 타이포그래피 범위를 확장했다.
- 검증: 전역 토큰과 각 화면의 `data-pixel-font` 적용 범위를 연결 커밋별로 대조했다.
- 관련 커밋: `c9b2f8e`, `fe8391d`

## 2026-07-08 · 공용 아이콘·내비게이션 확장

- 알림·계정·역할·조직·카탈로그용 픽셀 아이콘 세트를 보강했다.
- ERP 사이드바의 하위 메뉴에도 각 기능 아이콘을 표시하도록 연결했다.
- 검증: icon export, 정적 SVG와 사이드바 매핑을 현재 구현에서 확인했다.
- 관련 커밋: `18e6c16`, `078ca53`, `74058ca`, `6349678`, `758b40f`, `26b1b0b`

## 2026-08-28 · 내비게이션 헤럴딕 아이콘 교체

- 세력도, 명예의 전당, 인벤토리, 교환·전달, 편의점, 샘플 연구소, 병기부, 주식 아이콘을 16~24px에서 식별 가능한 단색 헤럴딕 SVG로 교체했다.
- 병기부 조직도 인라인 아이콘과 공개 SVG mirror를 같은 body로 맞추고, NOVUS 아이콘 마스터의 대상 8종 및 누락된 VTT 운영 경로를 현재 내비게이션과 동기화했다.
- 검증: NOVUS 아이콘 감사 115종·내비게이션 경로 38개, SVG XML·body parity, 자산 감사·테스트 12건, `pnpm typecheck`, `pnpm lint`, 인증 로컬 ERP 1440px·390px 브라우저 확인을 통과했다.
- 관련 구현 커밋: `6b405b8c`

## 2026-08-28 · 자료실·GM 내비게이션 헤럴딕 아이콘 교체

- 위키, 기록보관소, 연대기와 관리자·VTT·사용자·크레딧·주식·대사 비프·인벤토리·신규 품목·투표·캐릭터 운영 아이콘을 16~24px용 단색 헤럴딕 SVG로 교체했다.
- 플레이어 메뉴와 공유하던 GM 아이콘을 전용 공개 SVG·React export로 분리하고, NOVUS 마스터의 내비게이션·페이지 계층·GM 그룹 및 병기부 그룹 렌더 호스트를 동기화했다.
- 검증: NOVUS 아이콘 감사 125종·내비게이션 경로 38개, SVG XML·`currentColor` fill-only 계약, 마스터 JavaScript, 자산 감사·테스트 12건, `pnpm typecheck`, `pnpm lint`, 인증 로컬 ERP 1440×1000·390×844와 마스터 브라우저 확인을 통과했다.
- 관련 구현 커밋: `2e43cc7a`

## 2026-08-30 · 캐릭터·조직 헤럴딕 아이콘과 Icon Sync 보강

- 캐릭터·프로필·장비와 신원조회 조직 31종을 built-in 이미지 생성·축약·벡터 정규화로 교체했다. 재무·적대세력의 공용 alias를 포함한 SVG 33파일과 OrgIcon을 동기화했다.
- 캐릭터 내비게이션·활성 무기·활성 방어구 전용 항목을 추가해 NOVUS 마스터를 128종으로 확장했다. 모든 정의의 그룹 렌더링을 검사하고, 인벤토리·위키 장비 분류와 명예의 전당의 현재 내비게이션 상태도 소스에 맞췄다.
- 이전 두 배치 21종은 로어·실제 기능 재감사 후 유지했다. 근거·미확정 경계와 재현용 축약 프롬프트는 `docs/design/novus-heraldic-icon-audit.md`에 기록했다.
- 검증: 동기화·조직·자산 테스트 51건, 아이콘 감사 128종·38경로, SVG XML 33파일·body parity·master JS, `pnpm typecheck`, `pnpm lint`, 자산 감사, 인증 로컬 1440×1000·390×844, 마스터 128종 전체 렌더와 콘솔 오류·경고 0건
- 관련 구현 커밋: `eb144b4e`
- 운영 경계: DB·권한·경제·Query 동작은 변경하지 않았으며 배포·push는 실행하지 않았다.
