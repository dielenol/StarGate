# 제노 연구소 안내 NPC 후보 원장

## 용도

이 문서는 `/erp/research`의 초기 안내 캐릭터 뼈대에만 사용한다. 정식 NPC 신원조회 spec, `characters` 적재 payload, 소속 그래프 입력으로 사용하지 않는다.

## 승인 원장

| 항목 | 값 | 상태 | 근거 |
|---|---|---|---|
| 표시명 | 제노 | 사용자 확정 | 현재 사용자 지시 |
| 성별 | 남성 | 사용자 확정 | 현재 사용자 지시 |
| 화면 역할 | ZULU 격리 개체 제출·재료 추출 안내 | 사용자 확정 | 현재 사용자 지시 |
| 말투 | 무례하고 비꼬며 재수 없는 남성 캐릭터 | 사용자 확정 | 현재 사용자 지시 |
| 기준 대사 | “흐흣 쓰레기가 오셨군요” | 사용자 확정 | 첨부 대화 원문 |
| 초상 | `/assets/npcs/Xeno-profile.webp` | UI 후보 승인 범위 | 현재 첨부 이미지에서 로컬 누끼 |
| 영문 코드네임 | 미정 | blocked | `XENO`·`ZENO` 중 확정 근거 없음 |
| 실명·별칭 | 미정 | blocked | 근거 없음 |
| 소속·부서 | 미정 | blocked | 근거 없음 |
| 권한 등급 | 미정 | blocked | 근거 없음 |
| 공개 여부 | 미정 | blocked | 근거 없음 |
| 나이·신장·체중·국적 | 미정 | blocked | 근거 없음 |
| 배경·관계 | 미정 | blocked | 근거 없음 |

## UI 허용 범위

- 화면에는 한국어 표시명 `제노`만 사용한다.
- 대사는 사용자의 말투 지시를 벗어나 신원·배경·관계를 새로 만들지 않는다.
- ZULU 레시피는 등록된 항목만 노출하고, 미등록 격리 개체는 제작 결과와 가격이 확정될 때까지 비활성으로 둔다.
- 정식 Dossier 등록은 blocked 항목이 확정된 뒤 별도 spec과 payload로 진행한다.
