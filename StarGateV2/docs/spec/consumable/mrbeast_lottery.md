## 설명

미스터비스트 복권은 미스터비스트 소다 기간 한정 구매 이벤트로 지급되는 1회용 스크래치 복권이다. 전용 화면에서 은박 영역을 긁어 당첨 결과를 확인한다.

## 배경

미스터비스트 소다 판촉 기간에만 배포되는 이벤트 경품이다. 복권의 추첨 결과는 사용 시 확정되며, 결과를 확인하면 등급에 따른 크레딧이 지급된다.

## 획득 경로

이벤트가 활성화된 기간에 미스터비스트 소다를 구매하면 구매 수량과 같은 수량의 복권을 구매 캐릭터가 획득한다. 복권은 일반 판매 및 캐릭터 간 거래 대상이 아니다. 지급 기간이 끝난 뒤에도 이미 받은 복권은 발급 당시 이벤트와 확률표에 귀속된 상태로 사용할 수 있다.

## 당첨 등급

- 꽝: 9.9999% / 0 CR
- 5등: 45% / 40 CR
- 4등: 35% / 60 CR
- 3등: 9% / 80 CR
- 2등: 0.99% / 800 CR
- 1등: 0.01% / 10,000 CR
- 0등: 0.0001% / 100,000 CR

## 비고

2등·1등·0등 당첨 결과는 전체 공지 대상이다. 0등 결과는 1등보다 강한 전용 시각 효과로 표시한다. 이벤트 기간은 신규 복권 지급에만 적용한다. 기간 종료 또는 이벤트 설정 변경 뒤에도 이미 지급된 복권과 진행 중인 추첨은 발급 당시 이벤트 ID·확률표로 계속 사용할 수 있다.
