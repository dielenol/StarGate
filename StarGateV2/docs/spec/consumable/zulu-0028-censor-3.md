## 설명
ZULU-0028에서 회수한 깨진 음절을 탄체에 하나씩 봉입한 네베드 전용 특수탄이다. `CMMG Mk.47 Mutant 「피안의 보루」`를 거치한 상태에서 `U2 파쇄음절탄 사격`으로만 사용할 수 있다.

## 배경
깨진 음절 3개를 각각 한 발에 봉입해 정확히 3발을 만드는 시즌 1 한정 시제품이다. 기존 소닉 이미터 연구 선택을 대체하지 않는 후속 일회성 제작물로 분리한다.

## 획득 경로
공용 인벤토리의 `broken-syllable` 3개를 소모해 CENSOR-3 3발을 제작한다. 공방 견적 수락 시 REGISTRAR 관료 표결이 자동 생성되며, 가결된 경우에만 완료품 수령 시점의 공용 재고를 다시 확인해 같은 트랜잭션에서 차감·지급한다. 수락 시점에는 조건부 재료를 예약하거나 차감하지 않는다.

## 사용 규칙

- 1회 사용마다 실제 캐릭터 인벤토리의 CENSOR-3 1발을 원자적으로 차감한다.
- 일반 소모품 사용 API로 직접 차감할 수 없으며 `U2 파쇄음절탄 사격`으로만 소비한다.
- 기본 소총의 거리별 물리 피해를 먼저 사용하고, 고정 30 심령 피해를 별도 추가한다.
- 추가 심령 피해는 DEF를 무시하며 캐릭터 ATK, 패시브, 상태 기반 피해 증가와 배율을 적용하지 않는다.
- CENSOR-3가 일반 탄환을 대신하므로 일반 탄창은 함께 차감하지 않는다.
- 시즌 1 총량은 3발이며 재장전·재제작·자동 보충하지 않는다.

## REGISTRAR 제작 승인 표결

- 투표 채널: `1534753076399833249`
- 고정 안건: `zulu-0028-censor-3-manufacture-v1`
- 투표 대상: 깨진 음절 3개를 CENSOR-3 3발로 가공하는 제작 권한
- 마감: 안건 생성 시각부터 6시간 뒤 자동 종료
- 통과 기준: 유효표 중 찬성표가 전체 유효표의 절반을 초과해야 한다.
- 정족수: 없음
- 동률·무투표: 반려
- 판정: 자동 마감 또는 권한 있는 조기 종료 시 같은 과반 규칙으로 결정한다.
- 승인 범위: 가결은 배치 제작 권한만 부여한다. 실제 집행은 연결된 공방 요청의 완료품 수령 절차가 담당한다.
- 가결 집행: 수령 시 공용 깨진 음절 3개 재고를 재확인하고 원자 차감한 뒤 CENSOR-3 3발을 지급한다. 부족하면 기본 장비를 포함한 수령 전체를 롤백하고 재시도를 허용한다.
- 부결 집행: 조건부 재료를 차감하거나 CENSOR-3를 지급하지 않고 기본 결과 장비만 수령한다.
- 사용 단계: 제작 완료된 탄환은 별도 발사 투표 없이 U2가 실물 1발만 원자적으로 차감한다.
