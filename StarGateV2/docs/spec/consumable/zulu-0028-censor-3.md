## 설명
깨진 음절 3개를 각각 봉입해 제작하는 전용 탄환 3발 세트다. 명명 후보 `CMMG Mk.47 Mutant 「피안의 보루」`를 거치한 상태에서만 발사할 수 있으며, 각 탄환은 기존 공격에 30의 방어 무시 심령 피해를 추가한다.
