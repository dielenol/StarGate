## 대사

## 외형
교신 기록으로만 확인된 인물이므로 외형은 확인되지 않았다.

## 성격
현재 보존 기록에는 섹터 C 지도부 교체안을 제안하고 현장팀의 질문에 답한 통신 발화만 남아 있어 성격 전반을 확정할 근거가 충분하지 않다.

## 배경
R은 섹터 C 사태 중 자신을 화이트로즈의 수장이라고 밝히며 해쉬 테거에게 연락한 인물이다. R은 로드리온과 게라쉬모프를 함께 실각시키고 화이트로즈 측 인사를 후임으로 파견하는 방안을 제안했다. 현장팀은 후계 적임자와 실각 절차의 선례를 질문했고, 이후 레짐 체인지 프로토콜이 가동되면서 니콜라이 바자로프가 새 감독관이 되었다.

R은 2028년 전쟁 계획과 병사 가족의 인질화에 관한 내용을 설명했지만, 이 내용은 통신 당사자의 증언으로 보존하며 독립적으로 확인된 사실로 일반화하지 않는다.

## 역할 상세
- 정규 소속: 시민사회(CIVIL) 산하 화이트로즈
- 확인 직책: 화이트로즈 수장(본인 발화 기준)
- 현장 개입: 섹터 C 지도부 동시 실각과 후임 파견 제안
- 노부스 오르도 권한등급: 해당 없음(외부 조직 인물)
- 현재 상태: 실명과 이후 행적 미상

## 이름 설명
`R`은 교신에서 사용된 식별명이다. 실명과 전체 이름은 확인되지 않았다.
