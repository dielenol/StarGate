## 외형
백발의 머리칼과 수염을 지닌 남성으로, 자신과 같은 흰색의 고양이를 항상 안고 다닌다. 너저분하고 오래된 18세기 중반풍 러시아 코트와 검은색 우샨카를 착용한다.

## 성격
학구적이면서도 차분하고 냉철하다. 책임 추궁보다 즉시 위험을 막는 일을 우선하며, 로드리온의 응답이 끊기자 독자적으로 발레리아의 격리를 해제하고 사보타주 대응 우선순위를 정리했다.

## 배경
니콜라이 바자로프는 섹터 C 연구원장으로서 고대 문명의 지식 가운데 `차원 균열`에 관한 박식한 정보를 보유한다. 발레리아 아젠트를 지구로 불러온 장본인이며, 다층차원관측실에 격리되어 있던 발레리아를 해방해 갑주를 돌려주었다.

전력 장애가 냉동 개체들의 해동으로 이어질 것을 경고하고 연구동과 유지시설을 포함한 세 구역이 사보타주를 당했다고 판단했다. 현장팀이 유지시설을 선택하자 발레리아에게 그들을 지원하도록 요청했다. 로드리온과 게라쉬모프 장군이 사망한 뒤 레짐 체인지 프로토콜이 그를 새 책임자로 지정했으며, 이후 섹터 C 연구원장에서 섹터 C 감독관으로 직책이 변경되었다.

## 역할 상세
- 직함 이력: 섹터 C 연구원장 → 섹터 C 감독관
- 정규 소속: 노부스 오르도 MANUS 섹터 C
- 전문 분야: 고대 문명과 차원 균열
- 능력: 미상
- 업무 범위: 격리 대상 관리, 비상 상황 분석, 현장 연구 지휘
- 확인된 조치: 발레리아 아젠트 격리 해제와 장비 반환
- 비상 판단: 전력 시설 파괴 시 냉동 개체 해동, 세 구역 사보타주
- 취임 경로: 레짐 체인지 프로토콜에 따른 새 책임자 지정
- 현재 상태: 섹터 C 감독관
