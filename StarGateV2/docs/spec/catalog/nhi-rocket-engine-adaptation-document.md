## 설명
NHI 로켓·우주 엔진 적응 문서는 로켓 추진과 우주 엔진에 비인간 지성체 기술을 적용하는 방법을 다룬 기밀 문헌이다.

## 배경
문서에는 1938년 이후의 미확인 비행체 회수와 NHI를 무기로 재구성하는 기록이 포함돼 있었다. 해당 내용은 아르고 기지 침투 당시 킴라박 리가 열람한 범위로 보존한다.

## 획득 경로
킴라박 리가 아르고 기지에서 1건을 회수해 직속 상관 모리어티에게 전달했다. 모리어티가 곧 Montag-98에게 살해된 뒤 문서를 다시 확보한 인물이나 장소는 확인되지 않았다.

## 비고
카탈로그는 이 문헌의 존재와 마지막 확인 경로만 기록한다. 현재 소유자와 보관처가 없으므로 개인·공용 인벤토리에는 수량을 만들지 않는다.
