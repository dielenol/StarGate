# 관료 표결

REGISTRAR가 지정 관료 채널에서 단순 찬반 표결을 수집하는 운영 규격이다.

## Discord 직접 생성

1. 지정 관료 채널 `1534753076399833249`에서 `/관료투표 생성`을 실행한다.
2. 입력값은 `안건제목`, `안건내용` 두 개뿐이다.
3. REGISTRAR가 `찬성`, `반대`, `투표 종료` 버튼이 달린 공지를 게시한다.
4. 같은 사용자가 기한 안에 다시 선택하면 현재 표가 바뀐다.
5. 생성 시각부터 정확히 6시간 뒤 자동 종료한다.
6. 유효표의 과반이 찬성일 때만 가결한다. 동률과 무투표는 부결한다.

`투표 종료`는 Discord에서 직접 생성한 안건의 생성자 또는 서버의
Administrator/ManageGuild 권한자만 실행할 수 있다. ERP 고정 안건은 Discord
생성자가 없으므로 서버 관리자만 조기 종료할 수 있다.

`/관료투표`에는 `생성` 외 서브커맨드를 추가하지 않는다. 채널 접근 권한 자체를
관료 표결 참여 경계로 사용하며 별도 역할 옵션을 받지 않는다.

## ERP 고정 안건

ERP는 확정된 preset의 제목과 본문을 `bureaucrat_votes` 원장에 `PENDING`으로
등재한다. 웹 서버가 Discord 토큰으로 직접 발송하지 않는다. REGISTRAR가 원장을
polling해 같은 채널에 게시하고, Discord 전송 뒤 DB 응답이 유실되면 임베드에
기록된 원장 ID로 기존 메시지를 찾아 자동 연결한다.

표결 원장은 권한 승인 결과만 기록한다. 크레딧·재료 차감·제작 착수·완성품 지급은
각 운영 도메인의 별도 절차에서 처리한다.
